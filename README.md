# ⌨️ Typing Survival Game

An interactive and modern **Typing Survival Game** built using **HTML, CSS, and JavaScript**.  
The game challenges users to type continuously as new words appear endlessly. Players must type quickly and accurately before the timer runs out, making it a fun and engaging way to improve typing speed and accuracy.

2. Open the project folder.
3. Double-click **index.html** or open it in your browser.

---

## 🎮 How to Play

1. Click **Start**.
2. Type the word shown on screen.
3. Each correct word increases your score.
4. Timer resets after every correct word.
5. Game ends when time reaches zero.

Try to survive as long as possible!
